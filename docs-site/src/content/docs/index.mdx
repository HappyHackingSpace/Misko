## What is Mişko?

Mişko is an **internal, on-prem SaaS** for biology labs that run behavioral
tests on mice. It is the **system of record** for the lab workflow — subjects,
environments, scenarios, tests and summary results — while the heavy
computer-vision work (frame telemetry, tracking, video) lives in a **separate,
independent service**.

<CardGrid stagger>
  <Card title="Paradigm-as-code" icon="seti:typescript">
    Scientific test types (MWM, Open Field, EPM, Rotarod) are defined in code as
    SOLID specs as a read-only catalog. Labs create named environments from them
    and fill in apparatus values per environment.
  </Card>
  <Card title="Scenario-centric domain" icon="approve-check">
    A scenario bundles one or more environments (and their paradigms' metrics),
    so an experiment is defined once and a test is just pick a subject and run
    it environment by environment. Results are data, not pass/fail.
  </Card>
  <Card title="Two independent systems" icon="puzzle">
    Mişko keeps summary metrics + artifact URLs. The CV service owns raw
    telemetry and video in its own database. One thin contract connects them.
  </Card>
  <Card title="Internal SaaS, single-tenant" icon="setting">
    One laboratory per installation. No public sign-up — the superadmin is
    bootstrapped at startup and manages users from inside.
  </Card>
</CardGrid>
