## What is Mişko?

Mişko is an **on-prem system** for biology labs that run behavioral tests on
mice. It is the **system of record** for a study: the design, the animals and
what they received, the filmed test sessions and the reviewed results. Video
analysis runs in separate **workers**; the API computes every metric from the
trajectory a worker uploads.

<CardGrid stagger>
  <Card title="Paradigms as code" icon="seti:go">
    Test types (Morris water maze, novel object, pole test, treadmill) are
    defined in code in published versions that never change, with their
    metrics, events and quality rules. Labs create environments from them.
  </Card>
  <Card title="Study-centred design" icon="approve-check">
    An experiment has groups with roles, regimens, timepoints, protocols and
    endpoints. Animals are allocated once, dosed daily and tested in filmed
    sessions. Results are data, not a pass or fail.
  </Card>
  <Card title="One definition per measurement" icon="puzzle">
    Workers track the animal and upload a trajectory and an annotated video.
    The API verifies them, applies quality rules and computes every metric
    and event; a person accepts each result before it counts.
  </Card>
  <Card title="One laboratory per installation" icon="setting">
    No public sign-up: the setup command creates the superadmin, who creates
    every other user with a role.
  </Card>
</CardGrid>
